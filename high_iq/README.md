# High IQ: how rare it is and where it comes from (TikTok, 60 s)

Output: `../high_iq_tiktok.mp4`. 1080x1920, 30 fps, H.264 High + AAC-LC 48 kHz stereo, exactly 60.000 s (1800 frames).
Loudness is −14 LUFS integrated with a true peak of about −0.8 dBFS.

Everything is generated by the code in `src/`. There is no stock footage, there are no samples and no music files.

| Step | File | What it does |
|---|---|---|
| Script | `src/script.py` | 19 sentences with their scene and pause (no "Follow for more" outro: the video ends on the "IQ ≠ ALL INTELLIGENCE" ring). Each caption token is `digits\|spoken words` (for example `130?\|one-hundred-thirty?`), so captions show digits and the TTS reads words. |
| Voice | `src/voice.py` | Chatterbox TTS (Resemble AI), exaggeration 0.55, cfg_weight 0.4, temperature 0.75, one sentence at a time. The deep male narrator timbre is cloned from a 10 s reference line made with edge-tts `en-US-ChristopherNeural` (`build/ref_christopher.wav`). Each clip is transcribed with faster-whisper and regenerated with a new seed unless it is word-perfect and naturally paced. |
| Assemble | `src/assemble.py` | Joins the clips with short pauses and fits them to 60 s: up to 5 % speed change (`atempo`), then pauses compressed toward 0.16 s. Runs faster-whisper `medium.en` (`word_timestamps=True`) on the finished voiceover and aligns its words to the script, which fixes transcription mistakes. Writes `build/timeline.json` with scenes, word times and visual/sound events. |
| Sound | `src/mix.py` | numpy/scipy whooshes (transitions), pops (numbers and icons), a riser into the 160+ reveal plus an impact, a bell ding for the gold dot, and an original 80 BPM lo-fi bed (pads, FM e-piano, sub bass, soft drums, vinyl hiss). The bed is sidechain-ducked about −20 dB under the voice, then the mix is normalized to −14 LUFS and limited to −1 dBFS. |
| Video | `src/render.py` | skia vector rendering with neon blur glows, a moving grid and particles. Seven scenes are driven by the word timestamps, with zoom, whip-pan, glitch and slide transitions. Captions show 2–4 words at a time in white Inter Black with a black outline, the spoken word in yellow, in the lower-middle area clear of the TikTok UI. |

## Rebuild

```bash
# audio side (Python 3.11 venv: chatterbox-tts pins torch 2.6)
uv venv -p 3.11 /opt/cbx && . /opt/cbx/bin/activate
uv pip install chatterbox-tts faster-whisper num2words pyloudnorm "setuptools<81"
cd high_iq/src
python edge_say.py "<10 s reference line>" en-US-ChristopherNeural ../build/ref_christopher.mp3 -4%
ffmpeg -i ../build/ref_christopher.mp3 -ar 24000 -ac 1 ../build/ref_christopher.wav
python voice.py            # build/clips/*.wav
python assemble.py         # build/vo.wav, build/timeline.json
python mix.py              # build/mix.wav
deactivate
# video side (system python: pip install skia-python numpy pillow; apt install libegl1)
python3 render.py video    # build/video.mp4
python3 render.py mux      # ../high_iq_tiktok.mp4
python3 render.py preview 4.6 24.3   # PNG stills for checking
```

Model weights are downloaded from huggingface.co (Chatterbox, faster-whisper).
