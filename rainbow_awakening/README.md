# "Rainbow Awakening": blocky 3D TikTok short

- **`final_tiktok.mp4`**: the video. 1080x1920 (9:16), 30 fps, exactly **2700 frames = 90.00 s**, H.264 High + AAC 48 kHz stereo.
- **`captions.srt`**: one subtitle per on-screen caption chunk, timed to the voice.
- **`preview_lowres.mp4`**: the quick 540x960 timing preview (rendered every 2nd frame).

All visuals, the voice, music and sound effects are generated by the code in this folder. There are no
external art, music or sound assets, and no Roblox logos, characters, fonts or assets. The characters,
town, crystal and effects are original blocky designs. The caption font is Lilita One (SIL Open Font
License, from the npm package `@fontsource/lilita-one`).

## How it is made

| Step | File | What it does |
|---|---|---|
| Script | `src/script.py` | Scene windows, the 23 voice lines (= captions), emotion per line, caption chunk splits (max 7 words) and the rarity-word colors. |
| Voice | `src/voice.py` | Kokoro-82M neural TTS. Max's voice keeps one timbre (the decoder half of the `am_liam` style vector) and changes only prosody per emotion (excited, nervous, sad, shocked, hyped). A pitch + formant shift (x1.12, rubberband) makes it a ~10-year-old boy (median pitch ~245 Hz). Every line is checked with Whisper-small: it must transcribe to exactly the caption text. Whisper's word timestamps drive the caption timing. The script places lines without overlaps inside their scene windows and writes `build/vo.wav`, `build/timing.json` and `captions.srt`. |
| Soundtrack | `src/audio.py` | Original synthesized score (upbeat game groove for the intro and tiers, dark drone for the black aura, tense pulse at the crystal, sad piano at sunset, build + epic finale), all requested sound effects at the matching picture events, and crowd reactions (laughs, gasp, cheers, "whoa") made from layered, pitched-up Kokoro voices. Music is ducked about 7 dB under the voice. The mix is normalized to -14 LUFS with a look-ahead true-peak limiter at -1.5 dBTP. |
| 3D scenes | `web/*.js` | Three.js r170 rendered in headless Chromium (WebGL2 on SwiftShader, CPU only). `world.js`: sky and lighting presets, baseplate ground, radial town, plaza, the Awakening crystal (cracks, light beams). `character.js`: blocky rig with poses and face expressions (Max: blue hoodie, sneakers, brown hair). `fx.js`: flame aura shader (solid, rainbow, dark smoke with a white rim), particles, trails, shockwaves, beams, blocky confetti. `scenes.js`: the 12 scenes, cameras and events, synced to the voice word times. `overlay.js`: captions, bloom, vignette, flashes and the end card. Every frame is a pure function of time, so frames render in any order and in parallel. |
| Render | `src/render.js` | Playwright drives N Chromium workers and writes JPEG frames (q=0.95). Re-running resumes: existing frames are skipped. |
| Encode | `src/encode.py` | Two-pass H.264 (7 Mbit/s) + AAC 192 kbit/s, then ffprobe verification: exactly 2700 frames, video, audio and container durations 90.000 s. |

### Caption style
White Lilita One with a thick black outline and drop shadow, centered at y=1085 of 1920 (the middle third,
clear of the bottom caption/description area and nudged left of the right-side buttons). Max 7 words per
chunk, max 2 lines, pop-in scale bounce. Rarity words are colored: purple, yellow, metallic gold, black with a
white glow, and an animated rainbow gradient.

## Re-render

Requirements: Python 3.11+, Node 18+, ffmpeg with librubberband, Chromium for Playwright.

```bash
cd rainbow_awakening
npm install                                   # three.js + caption font
pip install kokoro-onnx faster-whisper pyloudnorm soundfile scipy numpy pillow
tools/fetch_models.sh models                  # Kokoro + voices + Whisper-small, all from the npm registry

python3 src/voice.py --models models --out build --srt captions.srt   # voice + timings + captions.srt
python3 src/audio.py --models models --build build                    # music + SFX + final mix

node src/render.js --w 540 --step 2 --workers 3 --out frames/preview  # quick low-res preview frames
python3 src/encode.py preview                                         # -> preview_lowres.mp4

node src/render.js --w 1080 --workers 3 --out frames/full             # full-quality frames
python3 src/encode.py final                                           # -> final_tiktok.mp4 + ffprobe check
```

Other useful commands:

```bash
node src/render.js --w 540 --times 1.5,30,79 --out frames/stills      # single stills at given seconds
python3 tools/contact_sheet.py frames/stills sheet.jpg 8 240          # labeled contact sheet
```

To change a line: edit `src/script.py`, then run voice, audio, render and encode again. The renderer reads
the new word timings from `build/timing.json`, so captions and synced events follow automatically.
